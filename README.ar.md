# مهارة إنشاء فيديو دليل مستخدم

[English](README.md) · [المهارة بالعربية](SKILL.ar.md) · [المهارة بالإنجليزية](SKILL.md)

مهارة قابلة لإعادة الاستخدام مع وكلاء الذكاء الاصطناعي لإنشاء فيديوهات دليل مستخدم عربية من واجهات الأنظمة الفعلية. توثّق طريقة تصوير المتصفح، وإعداد السيناريو، والتعليق الصوتي والترجمة، والأسهم والمؤشر والتكبير التدريجي، والمونتاج بـPython وFFmpeg، وفحص جودة الناتج.

المستودع يحتوي **تعليمات تنفيذ**، وليس برنامجًا يولّد الفيديو بضغطة واحدة أو لقطات خاصة بأي نظام. النسختان العربية والإنجليزية تشرحان طريقة العمل نفسها؛ أدوات التصوير والصوت والخطوط والمونتاج يلزم توفيرها في بيئة التنفيذ.

## الاستخدام

أرفق ملف المهارة للوكيل واطلب مثلًا:

> طبّق هذه المهارة لإنشاء فيديو دليل مستخدم لنظام [اسم النظام]. استخدم الواجهة الفعلية وهوية النظام، واشرح الإجراءات بصوت عربي وترجمة وأسهم حمراء وتكبير تدريجي واضح. سلّم فيديو MP4 ومشروع المونتاج القابل للتحرير، ووثّق الفحوص المنفّذة فعليًا.

حدّد رابط النظام أو مسار المشروع، وبيئة العمل المصرّح بها، واللغة أو اللهجة، والجمهور، والإجراءات المطلوب شرحها، ومجلد التسليم. لا تحفظ كلمات المرور داخل ملفات المستودع؛ استخدم طريقة توفير الأسرار الخاصة ببيئة العمل.

للتثبيت كمهارة متوافقة مع Codex، ضع المستودع في مجلد مهارة مستقل مثل `~/.codex/skills/arabic-software-training-video/`، بحيث يكون `SKILL.md` في جذره. حافظ على أي نسخة موجودة مسبقًا بدل الكتابة فوقها دون مراجعة. استدعاؤها: `$arabic-software-training-video`.

## الأدوات المعتادة

Python، وPlaywright/Chromium، وPillow، وNumPy، وFFmpeg أو imageio-ffmpeg، وPyAV، ومزود صوت مصرح به مثل edge-tts، ودعم تشكيل العربية والخطوط. أدوات التفريغ والجداول وPDF اختيارية حسب التسليم. توضح المهارة وظيفة كل أداة، مع ضرورة التحقق من توفرها وتوافق إصداراتها قبل التثبيت.

## مبادئ التنفيذ

- التصوير من الواجهة الحقيقية، دون اختراع أزرار أو نجاح عمليات لم تحدث.
- الحفاظ على الهوية البصرية ومصادر التحرير.
- اتبع مواصفات الأسهم داخل المهارة: أحمر `#D52424` وحد أبيض، وموضع مرتبط بالعنصر، وحركة ناعمة واحدة متزامنة مع الشرح، ثم ثبات واختفاء هادئ. الأبعاد والتوقيتات إعدادات مقترحة قابلة للتعديل.
- توضيح الفرق بين تحريك لقطة ثابتة والتسجيل الحي.
- موسيقى أصلية أو مرخصة، مع الاحتفاظ بتراخيص الخطوط.
- حماية بيانات التشغيل، والحصول على تفويض لأي كتابة تجريبية.
- عدم اعتبار التفريغ الآلي أو الفحص التقني استماعًا بشريًا أو اعتمادًا رسميًا.

لا يحتوي المستودع قواعد بيانات أنظمة أو بيانات دخول أو إعدادات شبكات داخلية أو شعارات الجهات أو تصويرًا خاصًا بالمستخدمين. الأدوات والخطوط والخدمات والعلامات الخارجية تخضع لشروط أصحابها.
